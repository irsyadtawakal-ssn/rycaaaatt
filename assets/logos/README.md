# Logo resmi

Simpan di sini logo resmi tools dari halaman brand atau press tiap perusahaan, PNG atau SVG dengan latar transparan. Nama file huruf kecil, contoh: `chatgpt.png`, `gemini.png`, `claude.png`, `canva.png`.

Logo dipakai apa adanya: tidak diubah warna, tidak diputar, tidak digambar ulang. Kalau file resmi tidak ada, kartu aplikasi cukup menampilkan nama tools-nya.
